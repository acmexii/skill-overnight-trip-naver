# 네이버 블로그 근거가 있는 1박 2일 여행 스킬

국내외 목적지의 맛집과 관광지를 가까운 동선으로 묶은 1박 2일 여행 일정을 작성하는 Codex 스킬입니다. 특정 여행지를 고정하지 않으며, 별도의 이틀 우천 실내 일정과 답변 맨 아래에 검증한 네이버 블로그 개별 글 3개를 제공합니다. 실시간 검색으로 교통·운영·날씨 정보를 확인합니다.

## 주요 기능

- 역 출발부터 관광·식사·숙박 지역·역 복귀까지 연결된 일정
- 공식 관광 안내와 교통 운영기관을 우선한 정보 확인
- 예보와 관계없이 이틀 모두 사용할 별도 우천 실내 일정 제공
- 비 예보 시간대에는 기본 일정도 실내 중심으로 구성
- 관광지 주변 실제 식당·대표 메뉴와 대기시간을 반영
- 네이버 블로그 제목·작성자·게시일·관련성 확인
- 검색 요약만 확인한 경우 본문 열람 제한 표시
- 확인된 사실·추정 이동시간·가정을 구분

## 설치

비공개 저장소이므로 접근 권한이 있는 GitHub 계정으로 인증해야 합니다.

스킬 설치 기능이 있는 환경에서는 다음과 같이 요청합니다.

```text
$skill-installer https://github.com/acmexii/skill-overnight-trip-naver
```

수동 설치는 저장소를 개인 스킬 폴더에 복제합니다.

```sh
git clone https://github.com/acmexii/skill-overnight-trip-naver.git ~/.codex/skills/overnight-trip-naver
```

이미 같은 이름의 스킬이 설치되어 있다면 덮어쓰기 전에 기존 파일과 비교하세요. 설치 후 스킬 목록을 새로 확인하거나 Codex를 다시 실행하세요.

## 사용 예시

```text
$overnight-trip-naver [여행지]
```

```text
[여행지]를 [출발역]에서 출발해 대중교통으로 1박 2일 여행하고 싶어.
네이버 블로그 근거를 포함해 일정을 만들어 줘.
```

목적지만 입력하면 날짜 미정, 첫날 10시경 기준역 도착, 다음 날 17시경 같은 역 복귀, 대중교통·도보 중심의 기본 조건을 적용합니다. 여행일·인원·예산·출발역 등을 지정하면 우선 반영합니다.

## 실행 조건과 제한

실시간 웹 검색 도구를 사용할 수 있는 환경이 필요합니다. 네이버 블로그의 접근 제한이나 검색 결과 부족으로 글 3개를 확인하지 못하면 확인된 글과 부족한 사유를 안내합니다. 이 스킬은 블로그 본문이나 이미지를 포함하지 않습니다.

여행 일정을 제안하는 스킬이며 정기 실행을 등록하거나 열차·숙소 예약, 결제, 문의 발송을 수행하지 않습니다.
